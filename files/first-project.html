Joshika's First Project

Time to combine everything you learned: a small "About Me" page with a heading, text, a list, a link and some CSS.

Step 1: Write the HTML

Save this as about.html.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>About Joshika</title>
  <link rel="stylesheet" href="about.css">
</head>
<body>
  <h1>Hi, I'm Joshika!</h1>
  <p>I just built my first web page.</p>
  <h2>Things I like</h2>
  <ul>
    <li>Drawing</li>
    <li>Music</li>
    <li>Coding</li>
  </ul>
  <a href="https://www.wikipedia.org">Explore the web</a>
</body>
</html>

Step 2: Add the CSS

Save this as about.css in the same folder.

body {
  font-family: Arial, sans-serif;
  background: linear-gradient(135deg, #0b1b4d, #2563eb);
  color: white;
  max-width: 600px;
  margin: 3rem auto;
  padding: 0 1rem;
}
a { color: #38bdf8; }

What you used

🏗️

Page structure

html, head, body and title.

📝

Content

Headings, a paragraph, a list and a link.

🎨

Style

Fonts, colors and a gradient background.

Congratulations, Joshika!

You now know how to build and style a web page. Next, try changing the colors, adding an image, or creating a second page and linking the two together.
