CSS Styling

HTML builds the structure. CSS makes it look good. Here is how to start.

CSS basics

A CSS rule has a selector (what to style) and declarations (how to style it). Save your rules in a .css file and link it from your HTML.

/* selector { property: value; } */
h1 {
  color: royalblue;
  text-align: center;
}
<link rel="stylesheet" href="style.css">

Colors

Use color names, hex codes like #3b82f6, or rgb() values.

#1e3a8a
#3b82f6
#38bdf8
#8b5cf6
p { color: #3b82f6; }

Fonts

Change the look of text with font-family, font-size and font-weight.

Georgia, large and bold

Monospace, medium

h2 {
  font-family: Georgia, serif;
  font-size: 1.4rem;
}

Backgrounds

Set a solid color or a smooth gradient behind any element.

This box uses a gradient background.

.box {
  background: linear-gradient(135deg, #7c3aed, #38bdf8);
  padding: 1rem;
  border-radius: 12px;
}
