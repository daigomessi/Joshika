HTML Basics

Everything on a web page is built from small pieces called tags. Learn the most important ones here.

Tags and elements

A tag is a keyword inside angle brackets. Most tags come in pairs: an opening tag and a closing tag with a slash. Together with the content between them, they form an element.

<p>I am a paragraph.</p>

Headings and paragraphs

Headings run from <h1> (most important) to <h6>. Paragraphs use <p>.

<h1>Main title</h1>
<h2>Section title</h2>
<p>Some text goes here.</p>

Result

Some text goes here.

Links

The anchor tag <a> creates a link. The href attribute says where it goes.

<a href="https://www.wikipedia.org">Visit Wikipedia</a>
Visit Wikipedia

Images

The <img> tag shows a picture. It has no closing tag. Always add alt text that describes the image.

<img src="photo.jpg" alt="A sunset over the sea">

Common tags at a glance

<ul> and <li>

Make a bulleted list.

<strong>

Mark text as important (bold).

<div>

Group content into a block.

<br>

Start a new line.
